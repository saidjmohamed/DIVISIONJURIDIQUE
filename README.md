# ⚖️ DIVISIONJURIDIQUE — منصة قانونية جزائرية احترافية

<div dir="rtl">

منصة رقمية متكاملة تهدف إلى تسهيل العمل اليومي للمحامين والمكاتب القانونية الجزائرية، من خلال أدوات ذكاء اصطناعي متقدمة وقاعدة بيانات قانونية شاملة تغطي أكثر من 100 قانون جزائري.

## 🛠️ التقنيات المستعملة

### الواجهة الأمامية (Frontend)
- **Next.js 16** — إطار عمل React متكامل مع SSR/SSG
- **React 19** — مكتبة واجهة المستخدم
- **TypeScript** — كتابة كود آمن ومرتب
- **Tailwind CSS 4** — تنسيق سريع وعصري
- **shadcn/ui** — مكونات واجهة احترافية (Radix UI + Tailwind)
- **Framer Motion** — حركات وانتقالات سلسة
- **Recharts** — رسوم بيانية تفاعلية
- **React Query** — إدارة حالة الخادم

### الخلفية (Backend)
- **Next.js API Routes** — واجهات برمجة التطبيقات
- **Prisma ORM** — إدارة قاعدة البيانات (SQLite)
- **Upstash Redis** — تخزين مؤقت وتقييد الطلبات
- **AI Fallback System** — نظام ذكاء اصطناعي متعدد المستويات

### مزودو الذكاء الاصطناعي
1. **OpenRouter** — نماذج مجانية (GPT-OSS 120B, MiniMax M2.5, Nemotron 3)
2. **Google Gemini 2.5 Flash** — نموذج سريع ومدفوع
3. **Google Gemini 2.0 Flash** — نموذج مجاني (4 مفاتيح بالتناوب)
4. **Groq** — Llama 3.3 70B (سريع جداً، مجاني)

### النشر والاستضافة
- **Vercel** — استضافة سحابية
- **Caddy** — خادم ويب بديل
- **PWA** — دعم التطبيق التدريجي

## 🚀 التشغيل

### المتطلبات
- Node.js 18+ أو Bun
- npm أو bun أو pnpm

### التثبيت

```bash
# استنساخ المستودع
git clone https://github.com/saidjmohamed/DIVISIONJURIDIQUE.git
cd DIVISIONJURIDIQUE

# تثبيت التبعيات
npm install
# أو
bun install

# إعداد متغيرات البيئة
cp .env.example .env.local
# عدّل .env.local وأضف مفاتيح API الخاصة بك

# إعداد قاعدة البيانات
npx prisma db push

# تشغيل الخادم المحلي
npm run dev
```

### البناء للإنتاج

```bash
npm run build
npm start
```
